# shuruq ahmad asiri — Portfolio

بورتفوليو شخصي بصفحة واحدة، ثنائي اللغة (عربي RTL / إنجليزي LTR)، بخلفية ثلاثية الأبعاد (WebGL).

## المحتوى

- `index.html` — الصفحة كاملة (الستايل + القالب).
- `app.js` — النصوص (عربي/إنجليزي) والمنطق: تبديل اللغة والثيم، رصّة الخدمات، الكاروسيل ثلاثي الأبعاد، مشهد الشيدر.
- `runtime.js` — محرّك عرض صغير يربط القالب بالبيانات (بدون أي مكتبة خارجية).
- `three.min.js` — three.js r128 (مستضاف محلياً).
- `assets/` `icons/` `fonts/` — صور الأغلفة، أيقونات الأدوات، والخطوط (Alnaseeb، Peanut Crystal).

## تشغيل محلي

```bash
python3 -m http.server 8000
# ثم افتحي http://localhost:8000
```

## النشر

الموقع ثابت بالكامل (static) — لا يحتاج بناء. على Netlify: مجلد النشر هو الجذر `.` بدون أمر بناء.

## التعديل السريع

- النصوص كلها في أول `app.js` داخل الكائن `STR` (`ar` و `en`).
- الإيميل ورابط واتساب وتيك توك داخل نفس الملف.
- صور الأعمال: بدّلي قيمة `src` في `projects` / `works`، والصور توضع في `assets/`.
